### Relationship Logic

`tool_master.mounting_option_id`  
→ defines which mounting option must be used for mounting this tool

`tool_type_mounting_option`  
→ defines the mounting option itself  
→ for example: based on insert geometry, shank geometry, or form + geometry

`tool_mounting_feature_requirement`  
→ lists the required features within the given option  
→ for example: `insert_shape`, `relief_angle`, `tolerance_class`
