### Kapcsolati logika

`tool_master.mounting_option_id`  
→ meghatározza, hogy a szerszámot mely szerelési opció alapján kell szerelni

`tool_type_mounting_option`  
→ maga a szerelési opció definíciója  
→ például: lapkageometria alapján, szárgeometria alapján, vagy forma + geometria alapján

`tool_mounting_feature_requirement`  
→ az adott szerelési opción belül szükséges feature-ök listája  
→ például: `insert_shape`, `relief_angle`, `tolerance_class`
